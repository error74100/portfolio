Moxen Project

React + TypeScript + Vite 기반으로 제작된 숙박시설 소개 및 예약 문의 웹사이트입니다.
방문객을 위한 시설 소개 페이지와 QnA 게시판, 회원 인증 기능을 제공하며, 운영자를 위한 관리자 대시보드를 포함하고 있습니다.

기술 스택

  • Framework : React 19, TypeScript, Vite
  • Routing : React Router 7
  • Backend / DB / Auth : Supabase (@supabase/supabase-js)
  • State / Data : Zustand, TanStack Query (React Query)
  • Styling / UI : Tailwind CSS 4, shadcn/ui (Radix UI 기반), lucide-react
  • 기타 : Chart.js (관리자 대시보드 통계), Embla Carousel, Sonner(toast)

주요 기능 - 사용자 페이지

  • 메인, 소개(About), 안내(Information), 부대시설(Facilities), 주변환경(Environment), 오시는 길(Map) 소개 페이지
  • QnA 게시판 : 문의 작성/수정/삭제, 댓글(답변) 기능
  • 회원가입 / 로그인(이메일, Google·Github 소셜 로그인) / 비밀번호 찾기·재설정
  • 마이페이지(프로필 조회 및 수정)
  • FAQ(자주 묻는 질문) 노출

주요 기능 - 관리자 페이지 (/admin)

  • 관리자 전용 라우트 가드 (AdminOnlyLayout)
  • 대시보드 : 가입자·문의 현황 통계 및 차트(Chart.js)
  • 회원 관리
  • QnA(문의) 관리
  • FAQ 관리 : 등록/수정/삭제 및 공개 여부(공개/비공개) 설정
